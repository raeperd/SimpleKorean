# Changelog

Each entry names the version and the date.

## 0.1.0, 2026-10-08

- Forked from [AminBlg/SimpleEnglish](https://github.com/AminBlg/SimpleEnglish)
  at version 2.1.1 to build a Korean version of the skill. The upstream
  history is in that repository.
- Renamed the plugin, the skill, the hook, the output style, and the env var
  to `simple-korean`.
- Removed the ASD-STE100 rule catalog, the dictionary reference, the
  dictionary extractor, the English benchmark results, and the numbers that
  cited them. A Korean rule set will not reuse them.
- The rule content in SKILL.md, the system prompt, and the output style is
  still the English rule set from upstream. The Korean rule set comes next.
